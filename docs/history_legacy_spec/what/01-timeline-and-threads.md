# WHAT · 时间轴浏览与多线索对照

> HOW 细节见 [../how/08-timeline-rendering.md](../how/08-timeline-rendering.md)、[../how/09-thread-track-layout.md](../how/09-thread-track-layout.md)、[../how/10-interactions.md](../how/10-interactions.md)。

## 时间轴浏览

用户面对一个无限延伸的时间轴（从史前到未来），默认显示公元元年到 2000 年。

- **平移**：左键拖拽（内容跟随光标）或滚轮（每格滚 1/4 主刻度格）。
- **缩放**：Ctrl+滚轮，**鼠标指向的时间点保持不动**（锚定缩放）。刻度随缩放自动换档：从 1000 万年到 1 天共 48 档；主刻度为年时副刻度为月，月为刻度时副刻度为周（7 天），依次递进到时。
- **刻度文字**：按精度自动选择格式（`1949`、`1949/10`、`1949/10/01`、`14H`、`14:30:00`）；公元前显示为 `BC xxxx`。
- **悬停实时提示**：过鼠标的十字准线横贯画布，光标上方蓝色提示框显示当前 `年/月/日`；悬停在事件上时追加事件标题与时间。持续事件还会显示「标题（第N年/共M年）」，N 随鼠标位置实时变化。
- **横/纵切换**（坏损）：View → Axis Appearance Setting（Ctrl+T）本应提供横向/纵向切换和轴位置滑条，但对话框构造即崩溃，功能无法到达。

## 事件显示

- **单点事件**（如「1949年10月1日 新中国成立」）：画成带箭头的五边形，箭头指向时间轴，浅灰底色，固定宽度。
- **持续事件**（如「三国时期」）：画成青绿色矩形，长度随缩放变化。
- 事件条内显示标题文字（居中、可换行，但无省略号截断，长标题显示不全）。
- **双击**事件条打开编辑器查看/编辑完整内容。

## 多线索对照（Thread）

- 时间轴两侧可放置任意多条 Thread，每条 Thread 是一条独立的事件带，有自己的背景色（16 色自动轮换）。
- **添加**：在时间轴空白处右键 → Add Thread（点轴左侧加到左边，右侧加到右边）；或在已有 Thread 上右键 → Add Thread On Left / On Right（相对该 Thread 插入）。
- **载入数据**：Thread 上右键 → Load File，选一个 .his 文件，该文件的记录显示在这条 Thread 上。多条 Thread 挂不同文件即可对照（如「中国朝代」与「欧洲大事」并排）。
- **轨道（Track）**：每条 Thread 内部自动分出若干平行轨道，数量 = Thread 宽 ÷ 最小轨宽（默认 50px，可右键 Set Track Width 调整）。事件自动排布互不重叠；空间不足时多余事件堆叠在最外侧轨道。
- **移除**：Thread 上右键 → Remove This Thread。
- Thread 宽度由所在侧空间均分，不可单独设置。
