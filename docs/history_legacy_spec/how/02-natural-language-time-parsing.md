# HOW · 自然语言时间解析

> 模块：`History/Utility/HistoryTime.py`（解析管线）+ `History/Utility/to_arab.py`（中文数字）。用户文档：`README.md` 时间日期说明节（96-105 行）。设计动机见 [../why/02-time-philosophy.md](../why/02-time-philosophy.md)。

## 1. 入口与管线顺序

入口 `time_text_to_ticks(time_text)`（`HistoryTime.py:134-160`），头注释自称 "*** All you need is this function ***"。返回 TICK 列表；**取最小/最大的语义在调用方**。

**管线顺序即行为规格：**

### 第一步：拆分（`__split_natural_language_time_text`，`:248-274`）

1. **删除「约」字**（`SPACE_CHAR=['约']`，`:90-92, 256-257`）——近似时间被静默当作精确时间。
2. **预替换**（`REPLACE_CHAR`，`:94-99, 259-260`）：
   - `元月→1月`、`正月→1月`；
   - `世纪→00`——"前12世纪"→"前1200"，**世纪实际指向年份百位而非区间**（21 世纪→2100 年）；
   - `至今→[当前时间]`——在**模块加载时**用 `datetime.now()` 求值一次（形如 `[2024-01-01 12:00:00]`），此后进程内固定，长进程中「至今」会过期。
3. **方括号保护**（`:262-265`）：提取所有 `[...]` 内容单独保留、不被分隔符切割，再从剩余文本中移除方括号段。头注释 `:139`：标准 datetime 字符串必须放在 `[]` 里。
4. **分隔符统一**：`SEPARATOR` 列表（`:75-88`）全部替换为 `,` 后切分——包括 `,` `，`（半角/全角逗号）、`~` `～` `-` `–` `－` `—` `―` `─`（四种波形/连字符）、`至` `到`（中文）。
5. 结果 = 方括号内容 + 切分片段，剥去 `[]` 与首尾空白，丢弃空串（`:271-272`）。

### 第二步：逐段转换（`:148-159`）

每段依次尝试：

1. **标准 datetime 格式** `time_str_to_datetime`（`:163-181`）：`SUPPORT_DATE_TIME_STR_FORMAT = ['%Y-%m-%d %H:%M:%S', '%Y-%m-%d', '%H:%M:%S', '%Y%m%d']`（`:123`）逐个 `strptime`，全失败返回 None；传入已是 datetime 对象则原样返回（`:172-173`）。成功则 `datetime_to_tick`。
2. 失败则走**自然语言解析** `__single_natural_language_time_to_tick`（`:281-316`）：
   - **BCE 判定**：`str_includes(text.lower().strip(), PREFIX_BCE)` 子串包含判定。BCE 前缀表（`:101-116`）：`'bc','bce','before common era','公元前','前','距今','史前'`；命中则 sign=-1，否则 sign=1。CE 前缀表（`'ac','ce','common era','公元'`）定义了但**完全未使用**——默认无 BCE 字样即公元后（与 README:99 一致）。
   - **中文数字转换**：`text_cn_num_to_arab`（见 §2）。
   - **正则抽取**（`:64-66, 295-297`）：`年/月/日` 前面的连续数字（允许数字与单位间有空格）；**只取每类第一个匹配**，其余忽略。
   - **无「年」字样分支**（`:299-304`）：整段所有数字字符拼接成一个整数作为年份，月日固定 1 月 1 日；无数字则返回 None（该段丢弃）。即「任意含数字的杂文本都会被当成公元年份」——容错换准确性的刻意代价。
   - **有「年」字样分支**（`:305-316`）：year=sign×解析值；**year==0 强制改为 1**（无 0 年）；month 钳到 [1,12]；day 钳到 [1, 当月天数]（含闰年）；月日缺省钳到 1。
3. 结果为 None 的段被丢弃，不计入结果列表。

### 多时间点语义（调用方）

`HistoryRecord.__try_parse_time_tags`（`core.py:629-636`）：所有 time tag 用 `,` 拼接后解析，`since=min(ticks)`、`until=max(ticks)`——「公元前1000年1月1日 - 公元2000年10月30日」成为时间段（README:103 佐证）。**解析全部失败时 since=until=0.0**（float，与 int TICK 类型不纯，记录落在公元元年）。

## 2. 中文数字转换（to_arab.py）

- **数字字表**（`:5-41`）：阿拉伯数字字符本身（'0'-'9'）+ 中文小写 `〇一二三四五六七八九零` + 大写 `壹贰叁肆伍陆柒捌玖` + 异体 `貮、两`（=2）。
- **单位表**（`:42-56`）：L1 级 `十拾百佰千仟`（10/100/1000）；L2 级 `万萬`（1e4）、`亿億`（1e8）、`兆`（1e12）。
- **算法** `cn_num_to_digit`（`:59-108`，docstring 有完整说明）：**从低位到高位**（pop 尾部字符）扫描：
  - 遇 L1 单位：更新 `unit_l1`，标记 `digit_missing=True`；
  - 遇 L2 单位：大于历史最大 L2 则重置基准到它，否则 `unit_l2 *= unit`（支持「万亿」=1e4×1e8 组合）；`unit_l1` 归 1；
  - 遇数字字：`digit × unit_l1 × unit_l2` 累加，然后 `unit_l1 *= 10`（支持「二九九七九」离散数字串逐位拼接，docstring `:98` 明确离散数字不影响标准表达）；
  - **其他字符静默跳过**；
  - 结尾若 `digit_missing`（如孤立的「十」），补加 `unit_l1 × unit_l2`（「十」→10）。
- **文本级替换** `text_cn_num_to_arab`（`:111-120`）：正则 `[0-9〇一…兆]+` 抓取所有连续数字串，**去重、按长度降序排序**（避免子串先替换破坏长串），逐个替换为阿拉伯数字。
- 测试函数（`:125-190`）覆盖到「五万四千三百二十一万亿四千三百二十一万四千三百二十一」（54321000043214321）及混入散文的数字串提取。

## 3. 解析行为示例

| 输入 | 结果 | 依据 |
| --- | --- | --- |
| `公元前1000年1月1日 - 公元2000年10月30日` | 时间段 [BCE1000, CE2000] | 分隔符 `-`、BCE 前缀 |
| `184年2月-184年8月` | 时间段 [184/2/1, 184/8/1] | 月缺日钳到 1 |
| `前12世纪` | BCE 1200 年 | 「世纪→00」替换 + 「前」 |
| `约公元前3000年` | BCE 3000 年（「约」被删） | SPACE_CHAR |
| `[2024-01-01 12:00:00]` | 标准 datetime 精确解析 | 方括号保护 |
| `至今` | 模块加载时的当前时间 | REPLACE_CHAR |
| `1949` | 公元 1949 年 | 无「年」数字段默认年 |
| `二十年目睹之怪现状` | 公元 20 年（散文中的数字被当成年份） | 容错代价 |

## 4. 验收注意

- 解析容错语义**必须保留**（用户明确确认，根目录 `migration_analysis.md` §8.1）；但 BCE 月日映射与外推格里高利历可有细微差异，不作为验收不符项。
- UniversalHistory 在适配层复用此管线，解析出的 `(year, month, day, ...)` 直接交 `JDNTimestamp.from_ymd_hms()`；年份映射 `jdn_year = history_year + 1 if history_year < 0 else history_year`（无 0 年 → 天文纪年）。
